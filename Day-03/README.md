Day 3 of my Python learning journey - loops and collections.

This folder covers the two main loops (`for` and `while`) and the core
Python collections: **lists, tuples, sets, and dictionaries**.

## Topics Covered

- `for` loops and `while` loops
- `range()`, `break`, and `continue`
- Lists: indexing, slicing, and modifying
- Tuples: indexing, immutability, and unpacking
- Sets: unique values and basic set operations
- Dictionaries: key-value pairs

## Key Concepts

- Lists are **ordered and mutable** - you can change, add, and remove items.
- Tuples are **ordered and immutable** - you cannot change them after creation.
- Sets store **unique values** and automatically remove duplicates.
- Dictionaries store **key-value pairs**.
- Loops **repeat operations**, either over a collection or while a condition is true.

## DevOps Connection

- **Lists** → store multiple servers or resources.
- **Tuples** → represent fixed groups of values (for example: name, IP, port).
- **Sets** → handle unique values without duplicates.
- **Dictionaries** → represent structured information (for example: a server's details).
- **Loops** → process multiple resources.
