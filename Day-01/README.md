# Python Day 1

This folder contains my very first day of learning Python.
It is a beginner-friendly crash course covering the absolute fundamentals.

I already know programming basics (OOP, C++, C#), so the code here focuses on
learning Python's own syntax rather than programming concepts themselves.

This is the first module of my step-by-step Python learning journey toward
**DevOps and Cloud Engineering**.

## Topics Covered

- Printing output with `print()`
- Variables and variable naming
- Data types: `str`, `int`, `float`, `bool`
- User input with `input()`
- Comments
- Type conversion and type casting
- Strings
- String operations: `.upper()`, `.lower()`, `.find()`, `.replace()`, `in`
- Arithmetic operators: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- Assignment operators: `=`, `+=`, `-=`, `*=`, `/=`

## What I Practiced

- Printing messages with `print()`.
- Storing values in variables and inspecting their types with `type()`.
- Reading user input with `input()`.
- Converting types (especially string input into numbers).
- Working with text (strings) and common string methods.
- Performing math with arithmetic operators.
- Using assignment operators as shortcuts.
- Building a few small practice programs (sum and bill calculators).

## DevOps Connection

These fundamentals are the building blocks I will use later in my DevOps and
Cloud journey. For example:

- `print()` and `input()` help write simple automation and script output.
- Variables store values like server names, ports, and IP addresses.
- Data types are everywhere: `str` for names, `int` for ports, `float` for
  memory/CPU values, `bool` for flags such as `server_running = True`.
- `input()` is the start of interactive setup scripts.
- Arithmetic and assignment operators are used to calculate totals, averages,
  capacity percentages, and to build counters in automation.

These fundamentals prepare me for writing real scripts later for:

- Linux automation
- System administration
- DevOps scripts
- AWS automation
- CI/CD automation
- Infrastructure automation
