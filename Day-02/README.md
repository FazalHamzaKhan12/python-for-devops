## Key Concepts

- Comparison operators return Boolean values (`True` or `False`).
- Logical operators combine conditions.
- Conditional statements control which code runs.
- `range()` generates a sequence of numbers.
- Loops repeat code.
- `break` exits a loop.
- `continue` skips the current iteration.

## DevOps Connection

These basics are the building blocks of automation later on.

```text
Conditions
    ↓
Check system state

Loops
    ↓
Process multiple servers/files/resources

range()
    ↓
Repeat tasks a specific number of times

break / continue
    ↓
Control automation flow
```

These concepts alone do not make someone a DevOps engineer — they are the
first steps toward writing real automation.
